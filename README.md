# yogurt-guide

Telegram Mini App для канала [«А чё так вкусно?»](https://t.me/chotakvkusno):
гайд «Греческий йогурт — 50 рецептов», доступ — только подписчикам канала.

Бот: [@chotakvkusno_bot](https://t.me/chotakvkusno_bot)

## Что умеет

- **Гейт по подписке.** Мини-апп не отдаёт гайд никому, кто не подписан на канал.
  Подпись `initData` проверяется на сервере, подписка — через `getChatMember`.
  Статику гайда напрямую не достать: `private/guide.html` не раздаётся как файл.
- **База.** Пользователи, история подписок/отписок, обращения, события (что открывают, что ищут).
- **Обращения.** Форма внутри мини-аппа + любое сообщение боту в личку.
  Всё падает в таблицу `tickets` и пересылается в админ-чат.
  Ответ — реплаем на карточку обращения или из админки; уходит человеку в чат с ботом.
- **Админка.** `/admin` в боте → мини-апп со сводкой, обращениями и списком людей.

## Структура

```
private/guide.html   гайд как есть — заменяется новой версией один-в-один
src/inject.html      форма обращений + аналитика, вклеиваются в гайд при старте
public/gate.html     экран входа и гейт подписки
public/admin.html    админка
src/index.js         express: вебхук, /guide, статика
src/bot.js           логика бота
src/telegram.js      Bot API, проверка initData, сессии
src/db.js            запросы к Postgres
src/schema.sql       схема, применяется при каждом старте
```

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | да | Токен от @BotFather |
| `DATABASE_URL` | да | `${{Postgres.DATABASE_URL}}` |
| `SESSION_SECRET` | да | Случайная строка, подписывает сессии мини-аппа |
| `WEBHOOK_SECRET` | да | Случайная строка, ею же закрыт путь вебхука |
| `PUBLIC_URL` | да | Адрес сервиса, например `https://yogurt-guide.up.railway.app` |
| `CHANNEL` | нет | Канал для проверки подписки, по умолчанию `@chotakvkusno` |
| `CHANNEL_URL` | нет | Ссылка на канал |
| `ADMIN_CHAT_ID` | нет | Куда пересылать обращения. Узнать: `/id` в нужном чате |
| `ADMIN_TG_IDS` | нет | Кому открыта админка, id через запятую. Узнать: `/id` в личке бота |

Без `ADMIN_CHAT_ID` обращения только пишутся в базу, без пересылки.
Без `ADMIN_TG_IDS` в админку не попасть.

## Что нужно сделать руками

1. **Бот должен быть админом канала** `@chotakvkusno` — иначе `getChatMember`
   не отвечает и гейт не работает.
2. **В @BotFather** для `@chotakvkusno_bot`: *Bot Settings → Menu Button* →
   указать `PUBLIC_URL`. Тогда мини-апп открывается кнопкой меню.
3. Вебхук ставится сам при старте, руками ничего делать не надо.

## Команды бота

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | всем | Проверяет подписку, даёт кнопку с гайдом |
| `/id` | всем | Показывает `chat_id` текущего чата |
| `/admin` | админам | Кнопка в админку |
| `/stats` | в админ-чате | Короткая сводка текстом |

## Локально

```bash
npm install
BOT_TOKEN=... DATABASE_URL=... SESSION_SECRET=... WEBHOOK_SECRET=... npm start
```

Без `PUBLIC_URL` вебхук не ставится — для локальной отладки это то, что нужно.

## Обновить гайд

Заменить `private/guide.html` новой версией и запушить. Форма обращений
и аналитика вклеиваются автоматически — трогать вёрстку гайда не нужно.
Единственное требование к файлу: наличие `</body>` и блока `id="menuGrid"`.
